# NanoScripts

A single-page agency website for setting up automated QA infrastructure with Playwright, Docker, and GitHub Actions. Built with Astro, Tailwind CSS, and TypeScript.

## Development

Run these commands from this directory:

```sh
npm install
npm run dev
npm run check
npm run build
```

The site supports English, Russian, and Chinese, with language copy in `src/i18n.ts`. Dark mode follows the system preference on first visit and can be changed from the navigation.

Update the GitHub, LinkedIn, and email destinations in `src/pages/index.astro` to use your own contact details.
